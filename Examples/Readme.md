# KTT Examples

This folder contains example projects (Examples) that primarily act as convenient benchmarks for KTT developers.
They also demonstrate more advanced uses of KTT.

## Examples/Common
All Examples (except JSON, Microbenchmarks, and Examples using Python) include code from the Common folder.
The Common folder primarily contains classes ExampleBase, ExampleReferenceKernel, and ExampleReferenceComputation.
See the header files for documentation.

## Examples/Template
Template contains the skeleton of a typical Example, intended to be used for creation of new Examples.

## Examples/LegacyExamples
Contains old versions of Examples, before commit 681758a0 "Add first draft of Example base class". Used as references to test against.
