# SQLite 3.53.4

`sqlite3.c` and `sqlite3.h` are the unmodified SQLite amalgamation from `sqlite-amalgamation-3530400.zip`
(SQLite 3.53.4, 2026-07-24), taken from the bundled copy in SQLiteCpp 3.4.0.

They are compiled directly into KTT when building with `--database`, so no system SQLite installation is needed
on any platform.
